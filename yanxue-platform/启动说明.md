# Yanxue Platform 启动说明

## 服务概览

| 服务 | 说明 | 端口 |
|------|------|------|
| yanxue-mysql | MySQL 8.0 数据库 | 13306 |
| yanxue-redis | Redis 7 缓存 | 16379 |
| yanxue-server | Spring Boot 后端 | 18080 |
| yanxue-admin | Vue 前端 (Vite) | 13000 |
| yanxue-user | Vue 前端 (Vite) | 13001 |

## 启动顺序

### 1. 启动数据库服务（必须先启动）

```bash
docker start yanxue-mysql yanxue-redis
```

### 2. 启动后端服务

```bash
cd /project/bysj/yanxue-platform/yanxue-server
mvn spring-boot:run
```

后台运行：
```bash
nohup mvn spring-boot:run > /tmp/yanxue-server.log 2>&1 &
```

### 3. 启动前端服务

```bash
cd /project/bysj/yanxue-platform/yanxue-admin
npm run dev -- --host 0.0.0.0 --port 13000
```

后台运行：
```bash
nohup npm run dev -- --host 0.0.0.0 --port 13000 > /tmp/yanxue-admin.log 2>&1 &
```

## 一键启动

```bash
./start.sh
```

## 停止服务

```bash
# 停止前后端
pkill -f "yanxue-server"
pkill -f "vite.*yanxue-admin"

# 停止数据库
docker stop yanxue-mysql yanxue-redis
```

## 查看日志

```bash
# 后端日志
tail -f /tmp/yanxue-server.log

# 前端日志
tail -f /tmp/yanxue-admin.log
```
